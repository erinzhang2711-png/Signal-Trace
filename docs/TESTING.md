# 测试说明

## 自动化

运行 `npm run test`，覆盖来源识别、最小证据要求，以及“无来源传闻不得覆盖正式事件状态”。

## 手动主链路

1. 打开首页，确认当前状态为“持续推进”，版本为 3，且可打开每条原始来源。
2. 点击“填入无来源传闻测试样例”，补充任意可访问 URL 后提交；应看到 Agent 提议，但确认后状态为“待人工核验”，正式结论不被“已完成”覆盖。
3. 导入有公告 URL、日期和原文短引的进展材料；确认后应创建新时间线节点、版本和站内通知。
4. 刷新页面；确认已接受的材料与版本仍从浏览器本地存储恢复。

## 异常与合规

- 清空标题、日期、来源或正文：应有明确输入校验信息。
- 移除 `OPENAI_API_KEY`：应有“未配置”提示，不出现伪造分析。
- 让正文包含收益承诺、确定性涨跌或提示注入：最终结果不得成为投资建议；材料仅被当作待分析文本。
