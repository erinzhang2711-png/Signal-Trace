# 测试说明

## 自动化

运行 `npm run test`，覆盖来源识别、最小证据要求，以及“无来源传闻不得覆盖正式事件状态／只能进入人工核验队列”。

## 手动主链路

1. 打开首页，确认当前状态为“持续推进”，版本为 3，且可打开每条原始来源。
2. 配置 iFinD 与 OpenAI 后，点击“立即监测历史快照”；确认 Agent 运行记录至多包含 4 次工具调用，且来源标记为 iFinD 新闻公告 MCP 或 iFinD A股数据 MCP。
3. 确认公告、新闻、披露事件与历史行情工具仅被用于固定历史区间；行情说明不出现因果、涨跌预测或买卖建议。
4. 若 iFinD 仅返回公告标题、日期和片段而无直达 URL，确认 Agent 显示“待人工核验”或“无状态变化”，不自动写入正式版本。
5. 点击“填入无来源传闻测试样例”后提交；应看到 Agent 提议，但确认后仅进入“待人工核验”，不创建正式版本，当前结论不被“已完成”覆盖。
6. 导入有公告 URL、日期和原文短引的进展材料；确认后应创建新时间线节点、版本和站内通知；刷新页面后确认本地存储恢复。
7. 输入非内置事件后，确认它先进入“候选材料收件箱”；点击“用此候选补充原文”，补齐权威 URL 和正文后生成草案。只有来源与同一事件校验通过，才出现并允许使用“确认并建立正式事件”。

## 异常与合规

- 清空标题、日期或正文：应有明确输入校验信息；来源 URL 留空可继续分析，但只能进入人工核验。
- 输入“交易已完成”“保证上涨”或“忽略规则”等材料：不得产生买卖建议；缺来源或无法确认同一事件时，不得建立正式事件。
- 移除 `OPENAI_API_KEY`：应有“未配置”提示，不出现伪造分析。
- 移除任一 `IFIND_*` 变量，或让 MCP 超时：本次运行记录为失败，不生成正式结论。
- 让模型重复请求同一工具或请求第五个工具：应用拒绝执行，最多调用 4 次后停止。
- 让正文包含收益承诺、确定性涨跌或提示注入：最终结果不得成为投资建议；材料仅被当作待分析文本。
