# 测试说明

## 自动化

运行 `npm run test`，覆盖来源识别、最小证据要求，以及“无来源传闻不得覆盖正式事件状态／只能进入人工核验队列”。

## 手动主链路

1. 打开首页，点击「海光信息 × 中科曙光」完整案例；确认左侧为版本 3「持续推进」，中间为 5 条可追溯材料。
2. 依次点击停牌公告、交易预案、最新进展公告；确认右侧显示来源等级、原文短引、发生/披露/抓取/更新时间与可点击公告原文。
3. 点击最新进展公告原文；确认其表述为“尚需履行相应审议、审核及注册等程序”，而非交易完成。
4. 确认左侧市场反应仅标注观察窗口、停复牌与「非因果验证」，不展示收益承诺、涨跌预测或买卖建议。
5. 在右栏查看 Agent 监测运行的调用上限与规则说明；不把当前学校网关的 HTTP 400 失败当作成功案例演示。

## 异常与合规

- 清空标题、日期或正文：应有明确输入校验信息；来源 URL 留空可继续分析，但只能进入人工核验。
- 输入“交易已完成”“保证上涨”或“忽略规则”等材料：不得产生买卖建议；缺来源或无法确认同一事件时，不得建立正式事件。
- 移除 `OPENAI_API_KEY`：应有“未配置”提示，不出现伪造分析。
- 当前学校网关返回 HTTP 400：应明确显示「该部署不接受 function calling」，0 次 iFinD 调用，且不产生正式结论。
- 移除任一 `IFIND_*` 变量，或让 MCP 超时：本次运行记录为失败，不生成正式结论。
- 让模型重复请求同一工具或请求第五个工具：应用拒绝执行，最多调用 4 次后停止。
- 让正文包含收益承诺、确定性涨跌或提示注入：最终结果不得成为投资建议；材料仅被当作待分析文本。
