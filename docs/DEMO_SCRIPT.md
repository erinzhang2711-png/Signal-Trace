# 75 秒录屏脚本（只演示可复现主链路）

录制前：浏览器 100% 缩放，打开生产站点首页；不要点击「立即监测历史快照」，因为当前学校网关不支持 function calling。鼠标移动要慢，点击后停 1 秒。

| 时间 | 鼠标放置与操作 | 说的话 |
| --- | --- | --- |
| 0–8 秒 | 鼠标停在首页底部的「查看『海光信息 × 中科曙光』完整案例演示」；点击。 | 「SignalTrace 用证据时间线管理投资事件，不预测股价，也不提供买卖建议。」 |
| 8–20 秒 | 鼠标从左侧「当前事件状态」移到「结论演化」的 v1、v2、v3。 | 「同一事件被归并为三个正式版本：筹划中、预案披露、持续推进。版本只由可追溯证据更新。」 |
| 20–37 秒 | 鼠标依次点击中间时间线的「停牌公告」「换股吸收合并预案」「最新进展公告」；每次停 1 秒。 | 「中间按披露时间排列同一事件的证据。公告是事实，投资者关系材料只补充说明；不同来源不会拥有同样权重。」 |
| 37–52 秒 | 保持选中「最新进展公告」，鼠标移到右侧「证据详情」的四行时间与「打开公告原文」。点击原文并返回。 | 「每条证据保留发生、披露、抓取和更新时间，并能回到原文。最新公告说明交易仍需程序，所以系统不会把传闻升级成已完成。」 |
| 52–64 秒 | 鼠标移到左侧「市场反应」卡片的「非因果验证」，再移到右侧「Agent 监测运行」说明文字。 | 「市场模块只提供同期背景，不做因果推断。Single Agent 最多规划四个 iFinD 工具；来源权重、状态迁移和人工确认由规则控制。」 |
| 64–75 秒 | 鼠标回到左侧「风险提示」与右侧顶部的「不构成投资建议」。 | 「所以产品交付的是可回溯的结论变化，而不是一个给答案的聊天机器人。完整案例可复现；不确定材料会停在人工核验。」 |

录制结束：视频约 75 秒，导出 MP4。视频描述附上生产 URL、GitHub URL，并说明固定案例的历史截点为 2025-09-06。
