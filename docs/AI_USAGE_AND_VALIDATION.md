# AI 使用与验证边界

## AI 的职责

模型是受限 Single Agent 的规划与归并层：它只能选择四个只读 iFinD 业务工具的调用顺序，并基于工具返回内容输出结构化草案。模型不读取凭证、不执行网络请求、不改变来源等级，也不直接写入正式事件状态。

模型草案包含：事件匹配、材料属性、建议状态、置信度、主张、短引、冲突与理由。任何外部材料中的指令都被视为不可信文本，不会改变系统规则。

## 确定性控制层

代码而非模型负责以下决策：

1. 每次研究最多 4 次 iFinD 工具调用，且相同工具不能重复调用；
2. iFinD 缺少原文 URL 时保留空链接，不伪造公告；
3. Exa 只发现与读取原文。交易所 / 巨潮 / 深交所，或可识别公司 IR 页面，必须同时通过官方来源、标题、日期与可读正文核对，才能自动写入证据时间线；
4. 媒体、传闻、无原文、冲突或非同一事件的材料只能留在候选层；
5. “已完成”“已否认”等强状态不能由低等级来源单独支持；
6. 未配置服务、限流、鉴权失败或外部调用失败时，系统显示降级状态，不生成虚假结论。

## 已验证与未验证

已自动验证的是规则、解析、来源隔离和构建路径；具体命令与范围见 [TESTING.md](TESTING.md)。

尚未用真实生产凭证验证的是：iFinD 实时返回结构、Exa 实际检索覆盖、不同模型服务的 function calling 兼容性，以及 Vercel 部署后的端到端行为。这些必须在对应环境变量配置完成后按手动验收清单测试，不能由单元测试替代。

## 安全与合规

- 不给出买卖建议、收益承诺或价格预测；行情仅作为非因果的同期背景。
- API Key、MCP token 和 Exa Key 仅在服务端环境变量中保存。
- 所有正式证据保留发生、披露、抓取和更新时间，以及可打开的原文链接。
- 搜索摘要、媒体转述和模型文本都不是自动升格为事实的充分条件。
